## 三、风险与注意

| 项 | 说明 |
|---|---|
| 单实例 | 同一 bot 只能一个守护进程；本机测试进程必须先停 |
| Token 安全 | 环境变量存放，不硬编码；部署工作流用完即删 |
| 服务器资源 | 守护进程极轻量（长轮询挂起），无端口监听 |
